# iOS 工作台与主题试用

## 本轮范围

用户要求将青草预览先构建到 iOS 看实际效果；同时保留多主题并存的方向。默认青草，在“我的 → 外观与主题”提供森林、石墨、纸白、晴空、玫瑰燕麦、奶油杏、雾紫、青草8套配色。所有主题对所有用户开放。

本版实现共同工作台布局＋8套配色，不宣称已实现此前所有概念布局；Sliding Panes 横向叠页等结构仍为后续探索。Android 继续保持现有界面及2.9.1+10发布版本，不创建新Android Release。

## 实现

- `AppSkin` 集中定义配色和 ThemeData；`AppThemeController` 仅在 iOS 启动时加载、监听选择。
- `StorageService` 独立的 `ios_app_skin` 键保存选择，不改写午休/提醒设置。写入串行，失败回滚；SharedPreferences 原生写入返回false/异常时刷新内存缓存，避免假成功。
- `IosWorkbench` 消费真实考勤、CSV及 BOSS 单日状态；周日期条、当日工时、月度缓存累计、收尾清单、日志内容与底部固定主操作。
- 月度累计只读既有月度缓存与手工标记，标为缓存；数据不完整时显示破折号，不增加月度网络请求。改工时/恢复默认后即刻重算累计。
- 主题覆盖主导航、工作台、主题页和设置/月度/日志等旧页面及相关弹窗，红橙等业务状态保留。iOS启动页改为所选主题的简洁加载页；Android不变。
- 未来日期禁用，跨日期加载统一校验素材/汇总/更新时间；原有提交前防重与用户确认保持。
