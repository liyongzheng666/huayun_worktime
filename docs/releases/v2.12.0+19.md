华云工时 2.12.0 更新来啦 🍃

谢谢每一位认真试用、反馈问题的你！这次把工作台和填报核对一起补齐，让工时更清楚、填写更省心 🫶

这次更新了什么：

🏠 两端统一工作台
• Android 也使用和 iOS 一致的今日工作台、收尾清单与“今日 / 月度 / 日志 / 我的”导航。
• 新增青草、石墨等 8 套配色，可在“我的 → 外观与主题”选择，并保留你的主题设置。
• Android 原有后台打卡提醒、保活设置和 APK 更新能力继续保留。

🧮 工时更准确
• 修复远端 10.20 被显示成 10.19，以及编辑时仅改标题也可能带错工时的问题。
• 显示、手输、分钟换算和月度累计统一精度，保留两位截断规则，减少重复转换丢失 0.01 的问题。
• 旧精度缓存会在重新同步对应月份后更新；网络失败时保留原数据，并提示待核对。

🗓️ 整月建议与月底核对
• 把已填日报的多报、少报计入剩余额度，为未填日期生成 0.10 小时粒度的建议。
• 实际填报确认框直接显示本日建议、月度预算和尾差，可点击采用，再核对确认提交。
• 每月最后一个实际工作日（包含调休）打开 App，会弹出应填、已填和少填 / 多填差额；差额为 0 也会明确展示。
• 核对后相同摘要不反复打扰，工时变化后会再次提醒；数据未同步或当天工时未完成时显示“待确认”，不会当作 0。
• 无待填日期、已填超额或无法分配时，提示手动核对已有日报；不足 0.10 小时的尾差在月底核对处理。

🛠️ 填报细节修复
• “建议多待几分钟”只在实时当天出现，补填过去日期或查看未来日期时隐藏。
• 登录页加载失败可重试；提交、编辑后回读实际已填工时，日志页和月历同步显示。
• 减少单日更新后重复查询整月造成的等待，隐藏页回到前台时不再重复刷新；原有查重和最终人工确认保留。
• 继续跟进性能体验，遇到卡顿欢迎反馈具体操作步骤。

升级小提示 📦
• 直接覆盖安装，保留原应用数据和设置，不用卸载旧版。
• 首次更新会重新同步当前月份考勤；查看历史月份或生成建议前，请确认考勤与华天已填数据已同步完成。
• 工时建议只作辅助，采用后仍需你确认；本版不会自动改写远端历史日报或批量提交。
• 忙的话选“晚点再说”就好，稍后更新也可以。祝大家少点折腾，准点下班～🐱
