华云工时 2.12.2 更新来啦 🍃⚡

谢谢大家持续试用和反馈！这次把性能体检中发现的重复操作清理了一轮，也修好了“没填日报却显示已填 0 小时”的问题，周一上班前可以安排更新啦 🫶

📝 填没填，一眼看清
• 未填华天日报的日期明确显示“未填报”，不再显示成“已填 0.00 小时”。
• 尚未同步、已过期或查询失败时显示“待确认”；旧金额仅作为上次记录，不冒充当前结果。
• 已填报显示实际工时；若历史记录线索和零合计冲突，会提示核对。
• 日志页与月度详情统一状态，已打开的详情也能随同步结果更新。

⚡ 少做重复工作，减少等待
• 今日与月度在身份确认后分别加载，今日不用再等整月同步结束。
• 重复点击当前标签不再重新请求；未打开的日志页不提前读取整周数据。
• 合并同一日期的在途查询、短时间重复读取和密集强制刷新，避免反复开启后台会话。
• 月度核对改为一次读取金额与确认证明，减少无意义的设置写入和重复计算。
• 数据通知按月份处理，密集变化合并刷新；移除启动画面固定多等的一秒。
• 后台登录状态刚就绪时更快响应，较长等待继续低频探测。

🔐 登录记忆与准确性保护继续保留
• 2.12.1 的华天密码记忆仍可使用：实际密码认证成功后安全记住，工作日志右上角可管理或忘记。
• 明确强制核对、提交前查重及最终人工确认保留；结果未知的提交不会自动重试。
• 工时显示继续遵循两位精度规则，本版不会自动改写历史日报。

升级小提示 📦
• 直接覆盖安装即可，保留现有应用数据和设置，不要卸载旧版本。
• 旧缓存首次可能需要重新确认所属账号和月份；确认后可复用有效结果，避免每次打开都查整月。
• 如旧版从未记住过华天密码，下次实际登录时再输入一次并勾选“记住密码”。
• 实际同步速度仍受网络及华天服务响应影响。忙的话选“晚点再说”，方便时再更新就好～🐱
