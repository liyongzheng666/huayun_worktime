# 首次使用与新手引导排查

日期：2026-09-16。范围为首次启动、账号准备、首页下拉引导、功能说明、重放以及中途离开后的恢复，覆盖 iOS 工作台与 Android 每日工时页。

## 已确认问题与修复

| 场景 | 原有问题 | 修复后的行为 |
| --- | --- | --- |
| 点击“我知道了” | 外层 `IgnorePointer` 禁用整个引导，内层无法恢复按钮点击 | 只让提示卡和装饰图案穿透，按钮可点击；跳过直接收起并保存，不再声称已掌握手势 |
| iOS 首页内容不足一屏 | 滚动区域没有始终允许下拉，拉动不触发刷新 | 短内容也能下拉，iOS 与 Android 共用主动刷新完成入口 |
| iOS 成功刷新 | 没有设置旧的“用户下拉”标记，引导一直保留 | 只有本次主动下拉、当前页面可见且结果有效时完成引导 |
| Android 刷新失败、账号资料缺失 | 跨请求保存下拉标记，下一次自动刷新可能误报完成；缺资料也可被当作成功 | 移除跨请求标记，按单次请求与引导代次判断；失败、缺员工编号或无考勤结果均不报成功 |
| 切页、打开其它弹窗、跳过后请求才返回 | 迟到结果可能在别的页面弹庆祝，或重新出现已经关闭的引导 | 同时检查请求序号、引导代次、页面活动状态和当前路由；完成回调防重入 |
| 引导结束后查看功能说明 | 弹窗关闭和新页面跳转交织，重复操作可影响路由 | 先取回弹窗选择，再从仍有效的首页导航；完成弹窗关闭只处理一次 |
| 小屏、横屏、大字体 | 浮层互相重叠，庆祝弹窗溢出，功能说明标题和正文无法完整阅读 | 浮层按实际可用空间布局，紧凑高度隐藏装饰；庆祝内容可滚动，功能说明标题换行且整张卡片可滚动 |
| 设置页重新体验 | 只重置持久标记，仍需重启；初始化失败后恢复还有就绪状态遗漏 | 保存后立即通过首页切换入口重放，重新读取账号就绪状态 |
| 首次免责声明 | 系统返回可关掉必须确认的对话框，启动页永远等待；连点同意重复导航 | 拦截隐式返回，保存期间互斥，只调用一次确认回调 |
| 首次必选团队 | 禁止点击遮罩仍可通过系统返回跳过 | 必选时拦截系统返回；设置中的可取消选择保持可取消 |
| 账号或月度请求确认登录过期 | 初始化吞掉异常后，启动链继续请求每日页，重复弹失效提示 | 明确维护账号就绪状态，未就绪终止后续刷新，提供重新登录与重试；迟到失败不抢走用户已切换的页面 |
| 退出时 Cookie 清理失败 | 本地凭据未清或永久停在退出中；重启可能再次加载残留会话 | 本地退出仍完成，登录页先清理 Cookie，失败可重试；无 token 重启同样先清理，不直接加载旧会话 |
| 功能说明能力不准确 | iOS 被承诺实时检测打卡与自动跳过休息日；月度接口说明陈旧 | 按平台说明实际提醒能力，更新当前月度刷新行为与支持下拉的页面范围 |

## 实现范围

- 首页与入口：`daily_hours_screen.dart`、`main_screen.dart`、`settings_screen.dart`、`pull_refresh_guide.dart`、`ios_workbench.dart`。
- 启动与账号：`disclaimer_dialog.dart`、`team_selection_dialog.dart`、`monthly_calendar_screen.dart`、`startup_refresh_coordinator.dart`、`session_service.dart`、`login_screen.dart`。
- 功能说明：`feature_guide_page.dart`。
- 回归位于 `test/screens/*onboarding_test.dart`、`test/screens/disclaimer_dialog_test.dart`、`test/screens/feature_guide_page_test.dart`、`test/screens/login_screen_test.dart`、`test/screens/monthly_calendar_startup_test.dart`、`test/widgets/pull_refresh_guide_test.dart`，并扩展既有团队、会话和启动协调器测试。

复用原有存储键、刷新服务和导航入口，不新增依赖。核心简化为删除跨请求的下拉状态，让完成判断留在本次请求里；设置重放复用首页切换；功能介绍改成一个完整滚动区。
