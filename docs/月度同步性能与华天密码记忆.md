# 华云工时｜月度同步性能与华天密码记忆

## 本次需求（2026-11-15）

- 用户反馈月度页同步慢，暂不能区分考勤更新与华天已填工时同步；两个入口及组合流程都检查。
- Android和iOS都反复要求输入华天密码。用户明确要求一次填写后记住，后续会话失效能够恢复，避免每次重开App手输。
- 保留网页登录、验证码或额外认证的人工处理。错误密码不得无限自动重试；用户应能关闭记忆或清除已记住密码。

## 排查与实现约束

- 先建立实际Repository与生成JavaScript的可重复回归，记录请求数量、并发和等待顺序，再决定修复；本地回放不是实体手机或真实服务端性能数据。
- 稳定已确认空考勤可以成为智能更新停止边界；未知、缺卡或数据变化不得因为“空”被跳过。
- 华天整月查询仍在网页自身已验证会话中执行，不导出认证para到原生。异步脚本必须使用两平台能等待结果的桥接API，不能把Promise占位当作整月空表。
- 手工同步和自动刷新共享同月正在执行的只读查询；失败、登录失效与合法空月份明确区分。失败保留原缓存。
- 密码认证仍复用网页自身登录和加密流程。新增记忆功能应使用成熟系统安全存储；登录成功后才保存，密码不进入SharedPreferences、日志、异常详情、抓包或剪贴板。
- 自动登录只恢复执行前不可用的认证会话，不能重试结果未知的提交或编辑保存。凭据与主账号身份隔离，明确区分用户退出与自动会话过期。

## 验证与交付边界

对稳定空考勤停止、未知空考勤继续、同月并发合并、整月脚本并发上限/完整性、冷启动记忆、会话失效恢复、错误密码停止、取消记忆/退出清除、跨账号隔离分别回归。完成后运行全套测试和静态分析，再构建两端、核验正式签名与覆盖升级边界。Android正式发布与iOS安装分开记录；用户上一轮选择先完成Android发布，iOS安装仍暂缓。

## 月度同步已复现的原因与回归

- 智能更新只允许有上班卡的稳定日期作为停止边界。对已API确认且未变化的历史空考勤月，实际Repository回归从31次单日查询降为1次；当天仍为空时继续检查前一天，未知或缺少有效响应不当作确认零。
- 华天整月查询原先通过31次同步XHR串行执行，网络等待累加且阻塞网页事件循环。改为最多3个只读异步请求并发，仍完整确认整月；生成的真实JavaScript回归验证同步XHR为0、峰并发3、事件循环心跳可执行。
- 月度页手工同步原先绕过共享刷新服务，可与后台查询重复执行。现统一同月在途任务，回归验证手工与后台只发起一轮查询，同时保留未登录与失败原因。
- 全量考勤完成后旧页面先解除忙碌，再同步华天。实际Widget回归复现第二次点击造成重复考勤查询；现忙碌状态覆盖两个阶段并明确提示当前阶段，隐藏页不弹认证提示，迟到结果不覆盖已切换的月份。
- 异步查询设单请求10秒、整月30秒、原生桥35秒上限；任一天失败停止继续派发，整月结果不完整不写入缓存。Android/iOS共同使用可等待Promise的callAsyncJavaScript，并检查value/error。
- 相关服务与脚本60项、月度及主框架19项回归通过；这些是本地可控回放与Widget证据，尚未取得真实手机对真实服务端的耗时或体感结果。

## 密码记忆与身份隔离

- 旧设计只保存用户名，密码只用于本次隐藏网页登录；共享Cookie失效后自然需要再次输入。新功能不能找回旧版从未保存的密码，需在下一次实际密码认证成功时记住。
- 凭据范围使用已确认的团队与人员身份，而非变化的token。主账号token变化或退出撤销身份就绪；只有API团队身份确认后才允许读取对应安全凭据。旧账号API迟到不得为新账号激活旧凭据。
- 显式退出主账号关闭并尝试清除华天密码记忆；主账号自动过期暂时撤销身份，但保留已保存的凭据，待同一身份重新确认后使用。密码认证失败、账户锁定或需要额外认证时停止自动尝试。
- 既有Cookie已恢复只能证明会话有效，不能证明本次新输入的密码正确；不得据此把未经验证的新密码当作认证成功后保存。

## 2.12.1实现与验证

- 使用flutter_secure_storage 10.3.4：Android使用Keystore支持的加密存储，排除密钥与密文文件的系统备份/迁移，保留其他业务备份；iOS使用仅本机解锁可读的Keychain，并在三种构建配置启用对应entitlements。没有开启网页自身autoLogin。
- 同范围并发恢复合并一次真实密码认证，各业务操作至多执行一次。明确登录页及时恢复或返回人工流程，不再先空等完整会话超时；网络失败退避，确定密码/锁定/额外认证错误停用自动尝试。
- 登录完成前后、业务完成前后都复核当前身份。团队候选请求、用户选择、切换团队贯穿同一authRevision，旧账号迟到结果不激活新账号的密码范围。
- 工作日志顶栏始终提供“BOSS 登录与密码记忆”入口，避免原配置卡片隐藏后无法管理；可取消记住、忘记或走网页登录。
- 最终全套942项通过，静态分析无问题。真实Coordinator、Runner和平台替身验证首次手输成功后，冷启动新视图且Cookie失效仍无须再次输入；错误密码、并发恢复、未认证输入、身份变化与未知写入不重放均回归。
- 新建隔离Android API35模拟器，用真实BossCredentialsService和原生安全存储写测试凭据，杀进程重启仍读取成功；忘记后再次杀进程重启仍不存在。没有使用真实账号或向华天发送这些测试凭据。证据位于build/reports/boss-secure-native-persistence.json及同名log，诊断入口保留为.dart.txt，正式包使用lib/main.dart。
- iOS原生存储与真实华天网络认证尚未进行用户验收；本地回放中的请求数量改善不能当作真实手机提速倍数。
