# 华云工时｜双端统一与2.12.0发布

## 产品范围

用户于2026-11-15撤销“只同步业务、保留Android旧界面”的选项，明确二者归一。Android和iOS共用今日工作台、收尾清单、今日/月度/日志/我的导航、8套主题、月度填报建议、填报页提示、精度和月底差额核对。

原`IosWorkbench`类与`ios_app_skin`本地键名保留以免无关重命名或丢失既有主题；它们在两端使用相同Flutter组件，不引入iOS原生调用或强制Android使用iOS主题平台。

## 必要平台差异

| 能力 | Android | iOS |
| --- | --- | --- |
| 工作台、导航、主题、工时规则 | 共用 | 共用 |
| 系统后台打卡提醒 | 精确闹钟及触发时联网 | 固定文案的本地通知 |
| 厂商保活引导 | 保留 | 无此入口 |
| 发布安装 | GitHub Release正式签名APK，系统确认覆盖升级 | 按iOS签名授权安装，本轮未发布到App Store |

## 本轮细节

- 旧精度整月缓存必须重新同步，完成前不给误导建议；保留手工标记与登录数据。
- 月底在会话和启动同步就绪后弹窗，显示应填、已填、少填/多填，即使一致也明确0.00；未知不作零，核对签名按团队/人员/月隔离。
- 填报弹窗输入控制器保留至路由退场动画结束；取消、迟到校验和输入变化有保护。
- 隐藏页不重复查询BOSS或恢复刷新，暂停隐藏页动画；单日回读后仍可复用有效逐日凭据，减少重复查询整月。
- 正式包性能采样默认关闭；后续真机匿名帧采样需显式诊断构建。桌面基线及回归不能证明真机卡顿已全部解决。

## 发布和验收

版本为2.12.0+19，更新说明见`docs/releases/v2.12.0+19.md`，由现有App更新弹窗读取GitHub Release正文。发布不代表接收者已收到系统推送；启动检查或手动检查发现新版后展示，可稍后更新。

完整测试、正式构建、固定证书、覆盖升级、远端提交/tag/Release资产分别核验，结果记入操作记录。模拟器与Widget回归不替代真实账号和用户主观交互验收；未代用户提交华天日报。
